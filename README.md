### [Secured RAG IT Help Desk on Azure](https://github.com/keenan371/azure-secured-rag-helpdesk)

Built an AI help desk using sample documents, Microsoft Entra ID groups, managed identity, and group-filtered retrieval. Documented employee-versus-admin access tests, application decisions in Log Analytics, and authentication troubleshooting.

**Skills:** Python · Azure AI Search · Azure OpenAI · Entra ID · KQL · Access control

### [RedRabbit vs. Hugo — Local AI Red Team Lab](https://github.com/keenan371/redrabbit-hugo-ai-red-team-lab)

Built a local lab comparing a deliberately vulnerable baseline with hardened handling of four fixed, benign adversarial simulations. The documented hardened run classified, refused, and logged all four test cases. These results apply to the lab's controlled simulations.

**Skills:** Python · Agent boundaries · Prompt-injection simulations · Structured logging

**Skills:** Risk assessment · NIST AI RMF · Control-gap analysis · Technical reporting
