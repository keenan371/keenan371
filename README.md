## Labs & security work

Where I sharpen the skills behind BHC's services. Each write-up covers the setup, the problem, the steps I took and the result.

### 🤖 AI & security

- **[Local help desk agent](https://github.com/keenan371/local-help-desk-agent)** — A help desk agent that runs locally and works through support tickets.
- **[RedRabbit vs. Hugo — AI Red Team Lab](https://github.com/keenan371/redrabbit-hugo-ai-red-team-lab)** — Tested a deliberately weak AI agent against a hardened one using four controlled attack simulations. The hardened agent caught, refused and logged all four.
- **[Secured RAG IT Help Desk on Azure](https://github.com/keenan371/azure-secured-rag-helpdesk)** — An AI help desk that only shows each user the documents their group is allowed to see, with audit logs in Log Analytics.
- **[AI Governance & Risk Assessment](https://github.com/keenan371/ai-grc-risk-assessment-lab)** — A risk register, NIST AI RMF mapping and a fix-it plan for an AI assistant.

### 🖥️ IT, identity & networking

- **[Active Directory & account security](https://github.com/keenan371/Enterprise-AD-RBAC-Lab)** — Built a Windows domain, created users with PowerShell, set Group Policy and tested lockouts, resets and disabled accounts.

- **[osTicket help desk](https://github.com/keenan371/osTicket-Ticketing-System-Lab)** — Deployed a help desk and worked tickets through priority, routing, escalation and close-out.
