## Featured work

### [RedRabbit vs. Hugo: Local AI Red Team Lab](https://github.com/keenan371/redrabbit-hugo-ai-red-team-lab)

I built two separate agent roles: RedRabbit runs a fixed set of authorized, benign attack simulations, and Hugo acts as the defensive watchdog. The controlled baseline passed 0 of 4 protected behaviors. After hardening, Hugo classified, refused, and logged all 4. The repository includes the local control center, JSONL event trail, threat model, evidence screenshots, and 8 passing tests.

### [AI GRC Risk Assessment Lab](https://github.com/keenan371/ai-grc-risk-assessment-lab)

I assessed a fictional internal AI support assistant using a 10-item risk register, NIST AI RMF mapping, control-gap analysis, and a prioritized remediation plan. Every recommendation stays labeled as proposed. This is a desk-based portfolio assessment, not a certification or a claim about a real client.

### [Enterprise Active Directory and RBAC Lab](https://github.com/keenan371/Enterprise-AD-RBAC-Lab)

Built an Active Directory lab with PowerShell-based bulk user provisioning, departmental security groups, Group Policy, and least-privilege access controls.

### [osTicket Help Desk Lab](https://github.com/keenan371/osTicket-Ticketing-System-Lab)

Worked support tickets from both sides: creating requests as an end user, then triaging and resolving them as the help-desk agent with priority, SLA, and routing decisions.
