## Featured projects

### [Secured RAG IT Help Desk on Azure](https://github.com/keenan371/azure-secured-rag-helpdesk)

Built an AI help desk that retrieves sample documents according to the signed-in user's Microsoft Entra ID group. The project documents employee-versus-admin access tests, managed identity, application decisions in Log Analytics, and troubleshooting across deployment and authentication.

**What to review:** [Build, architecture, and evidence](https://github.com/keenan371/azure-secured-rag-helpdesk#readme) · [Application and queries](https://github.com/keenan371/azure-secured-rag-helpdesk/tree/main/app)

### [RedRabbit vs. Hugo — Local AI Red Team Lab](https://github.com/keenan371/redrabbit-hugo-ai-red-team-lab)

Built a local demonstration comparing a deliberately vulnerable baseline with hardened handling of four fixed, benign adversarial simulations. The documented baseline passed 0/4 protected behaviors; hardened mode classified, refused, and logged all four. Results apply to this controlled test catalog.

**What to review:** [Results and evidence](https://github.com/keenan371/redrabbit-hugo-ai-red-team-lab#verified-baseline-versus-hardened-results) · [Test suite](https://github.com/keenan371/redrabbit-hugo-ai-red-team-lab/tree/main/tests)

`Python` · `Prompt-injection simulations` · `Agent boundaries` · `JSONL logging`

### [AI Governance and Risk Assessment Lab](https://github.com/keenan371/ai-grc-risk-assessment-lab)

Assessed a fictional internal AI assistant through a 10-item risk register, NIST AI RMF mapping, control-gap analysis, and a prioritized remediation plan. Proposed safeguards are clearly distinguished from implemented controls.

**What to review:** [Executive summary](https://github.com/keenan371/ai-grc-risk-assessment-lab/blob/main/06_EXECUTIVE_SUMMARY.md) · [Risk register](https://github.com/keenan371/ai-grc-risk-assessment-lab/blob/main/02_RISK_REGISTER.csv)
